# AI Model Battles

The same prompt, given to different AI models, with every result public. Made by [@dean.builds.ai](https://www.instagram.com/dean.builds.ai) on Instagram.

If you came here from a reel by commenting a keyword, you're in the right place. Each battle has its own folder with:

- `PROMPT.md`: the exact prompt every model got
- one folder per model with the code it wrote, untouched
- `recordings/`: the footage used in the reel
- `README.md`: the rules, the scoreboard, and what each model got wrong

## The rules (the same for every battle)

1. **Same prompt, word for word.** It's in each battle's `PROMPT.md`.
2. **One design attempt, then a capped number of test rounds.** Each model can run its own project and fix errors, up to the cap stated in that battle's README. No human help, no edits to the code.
3. **Same tools for everyone.** Same test harness, same sandbox, same assets (none: everything is generated in code).
4. **Rankings are opinion.** I play or watch every result and rank them myself. Where I say something "felt" a certain way, that's my feeling, not a benchmark.
5. **Times and costs are only reported when they're comparable.** If they're not, I say so.
